## 第 2 版改了什么（`imitate/configs/prior-direct.json`）

- **查表当偏置**（`model.prior`）：阵容头和升级头输出 `查表 logit + 网络输出`，网络只学修正量。修正层初始化为 0，没训练时整个头就等于查表。
  - 升级：用同一张「回合 × 调度中心等级」升级率表；
  - 阵容：没上场的干员用按策略「新上了谁」的频率（和查表基线同一个计数器，排序完全一样）；已在场的干员用它自己的「留下率」（向总体留下率收缩，m=5）。
  - 训练局自己的偏置按局分 4 份、用另外 3 份拟合（`train.prior_oof`），测试局只用训练折拟合的表。
- **回合 × 等级直连升级头**（`model.level_direct`）：升级头另外读回合 token 和自己调度中心等级 token 的嵌入，经一个小 MLP。
- **修正量收缩**（`train.residual_l2`）：阵容 0.01、升级 1.0。不加时，升级头训到 30 轮以后修正量过拟合，把查表也带坏了。
- `default.json`（第 1 版）不变：第 0 折种子 0 重跑，指标和每轮 loss 和第 1 版逐位相同。

## 各列是什么

| 列 | 配置 |
|---|---|
| 第1版 default | 第 1 版原样，数字取自第 1 版那次运行 |
| prior | 只加查表偏置，不收缩 |
| direct | 只加回合 × 等级直连，不加偏置 |
| prior-direct λ0.01 / λ0.1 | 两样都加，两个头修正量收缩同为 0.01 / 0.1 |
| 第2版 prior-direct | 两样都加，收缩阵容 0.01、升级 1.0（= `configs/prior-direct.json`） |
| 只用查表先验（不训练） | 第 2 版结构、学习率 0，只跑种子 0（每折 1 次）。阵容 / 升级就是先验本身；**买牌那两行没有意义**（买牌头没有偏置，是随机初始化） |

完整配置都在同名 `.json` 的 `runs.<列名>.config` 里。
