## 怎么做的（逐回合）

1. **开局对齐**：引擎开 4 人 ABYSS 同盟局（owner = p0，队友 = 引擎 AI）。地图按上面第 5 条；R14 BOSS 用记录里的（第一局 假想敌：管 boss_3，第二局 卢西恩 boss_5）；band 按开局血量 + 白得的牌推（第一局 潘格尼尼、第二局 绮良）；禁用盟约只能从「记录里一张牌都没出现过」的盟约里取（引擎每局禁 7 个，记录只容得下 5 / 4 个，少禁的照实写）。
2. **每个准备回合开始**：先让队友 AI 打完它们的准备，然后把 owner 座位强制成记录的开局快照（`force.mjs forceSeat`；卡池份数照实归还 / 取出）。盟约人数以记录为准，引擎数不一样的地方（4_27 替身、变形同构体）用盟约人数补正对齐并列出。
3. **重放 owner 的操作**（`ownerturn.mjs`）：比较「开局快照」和「战斗棋盘快照」推出这回合的净操作——升级几次、从开局商店买了谁、卖了谁、哪些牌不在开局商店里（只能是刷新 / 合成奖励 / 机变 / band 来的，记录分不开）、哪件装备装给谁、谁站哪格朝哪。全部走引擎接口（`levelUp / buy / sell / equip / move`），引擎拒绝的照录。
4. **比对**：重放完和记录的战斗棋盘逐格比（干员、精锐、格子、朝向、装备、手牌、等级、盟约人数），差异照录，然后强制成记录（之后差异全部为 0）。
5. **战斗**：普通回合见第 6 条（敌人波次对齐）；BOSS 回合见第 3 条（队友配置 / 隐藏 BOSS / 种子对齐）。记录证明真实队伍进了 R15，所以 R14 替身队友不够隐秘核心门槛（全队激活层数 > 1200）时补上缺的层数；R15 开局按记录血量重开团队血池（否则 R14 的误差会带进 R15）。
6. **owner 单人打 BOSS**（`advisor/battle.mjs`，不受队友影响）：owner 这块棋盘单独在 BOSS 场上打，量「倒计时内打掉自己那一份血池（bloodPoint×1）的比例」——4 人同盟要赢，每人大致要在倒计时内打穿自己那一份。

## 对不齐的地方（不糊过去）

- **BOSS 回合是「对齐」出来的，不是复现出来的**：真实队友是谁、几个人还活着、R15 是哪只隐藏 BOSS，记录里都没有。上面第 3 条的组合只说明「存在一种队友配置能打出记录的血量」，不说明真实队友就是这样；owner 自己那块棋盘单独打 BOSS 的数（下表）和队友无关，事后诸葛亮里 BOSS 回合都用这个口径。第二局 R14 owner 自己单打卢西恩倒计时内只打掉自己那份的 77%、加时扣血前 97%——和真实局「进了加时、掉 2 血」吻合。
- **队友**：记录只有 owner 自己。引擎 AI 队友普遍打不到 R14（之前 50 局实测胜率约 5%），和真实局不符；所以凡是涉及队友的结果（团队胜负、R14 团队血量）都单独标注，主指标只用 owner 自己的场。
- **机变卡（R3/R9/R11）**：owner 拿了哪张记录里没有；引擎里 owner 座位的机变由 AI 代选（带来的悬赏怪会进 owner 的场），这一点在波次对齐里一并吸收了。
- **刷新**：每回合开局商店以外得到的牌，是刷新、合成奖励、机变还是 band 给的，记录分不开；它们在重放里统一记为「非开局商店得到」，不扣钱。开局商店买完 / 升级后剩下的钱（表里「剩 X 金」）就是刷新花掉或作废的上限。
- **装备合成**：客户端买第二件同名装备会自动合成「+」，记录只看到合成后的「+」；重放直接拿到「+」，所以 R14/R15 有一处「两件 vs 一件+」的差异，强制战斗棋盘后消失。
- **几处多出来的牌**（第一局 R10 多一张塑心精锐、第二局 R5/R8–R12 手里多一张）：引擎自己的 band / 特质在重放时又触发了一次（真实局里已经体现在记录里），战斗棋盘强制后消失，不影响战斗。
- **10-19 那段 R1 缺战斗快照、R2 缺开局快照**：R1 的战斗棋盘取 R2 第一行，已在表里标出。
