# 机制研究：缪尔赛思「策略」（`band_mlyss`）与「倒转」回路

> 更正上一版：**缪尔赛思既是策略（band）也是干员（T6, `maniShip` 调和）**。这一版按**策略**讲。
> 上一版写的「变形同构体 = 假成员」是干员侧的机制，两者可以叠用，见 §5。

## 1. 策略本体（引擎数据，`data/bands.json`）

```json
{
  "bandId": "band_mlyss",
  "name": "缪尔赛思",
  "desc": "【至纯凝结】在第1回合开始时获得一个进阶\n进阶：任意干员可装备，立即使该干员晋升为精锐干员",
  "buffs": [
    { "key": "preparation_start_gain_chess_from_round",
      "bb": { "round": 1, "count": 1 },
      "bbStr": { "type": "equip", "chess": "chess_item_5_06_e_b" } }
  ]
}
```

- 只发 **一次**（`round: 1`, `count: 1`）
- 发的是**金版**「博士投影」`chess_item_5_06_e_b`（普通版是 `_a`，要等下一回合才晋升；金版**装备即刻晋升**）

## 2. 「进阶 / 博士投影」到底做了什么（`data/items.json` 的 `implFormula`）

> Normal: equip onto any normal operator (occupies a slot until next round start), at the start of the next round
> destroy item and promote the operator to elite. **Golden: on equip, destroy item and promote immediately.
> On promotion, equipped items return to hand.**

三条关键：

1. **任意干员都可以**（不需要三张同名卡、不看阶数）
2. **晋升即刻、道具消耗**
3. **晋升时该干员身上的装备返回手牌** —— 也就是装备不随晋升丢失，可以立刻挪给下一张

## 3. 它为什么值钱：精锐把「获得时」特质整体翻倍

引擎里每个干员的「获得时」特质都有普通/精锐两版，精锐版**数值翻倍**。例如：

| 干员 | 普通 | 精锐 |
|---|---|---|
| 惊蛰（炎） | 获得 = 调度等级 ×1 层 | **调度等级 ×2 层** |
| 星熊 / 锏 | 自身所属盟约 +8 层 | **+16 层** |
| 烛煌 | 炎+维多利亚 +5 | **+10** |
| 缪尔赛思（干员） | 获得 1 个变形同构体 | **2 个** |

而精锐正常要 **3 张同名卡**（`goldenCopies = 3`）——T6 精锐等于要 3 张 T6。**缪尔赛思策略用 R1 一个道具把这个成本抹掉**：
省下 2 张池子 + 约 6–10 金，转手就能把最贵的那张 C（通常是 T5/T6）变成精锐。

## 4. 「倒转」的回路：层数 ↔ 金币 的正反馈（引擎里唯一自洽的一条）

我按引擎逐条排除了其它可能：

| 候选回路 | 结论 | 证据 |
|---|---|---|
| 买卖套利 | ❌ 不存在 | `config.economy.chessSell` 全阶 `normal=1 / golden=1` —— 精锐卖掉也只有 1 金 |
| 晋升再次触发「获得时」 | ❌ 不触发 | `server/match/player/acquire.js` 的 `promote()` 只换 id + 补池子 + `recompute()`，**不派发 onGain** |
| **层数 → 金币 → 更多牌 → 更多层** | ✅ 引擎里真实存在 | 见下 |

金币回流的两条引擎通道：

- **远见 `visiShip`**：每叠 10 层 → **+2 金**（`bond_layer_gain_coin`，`layer:10, count:2`）
- **奇迹 `miraShip`**：每 100 层 → **+20 金**（`layer:100, count:20`）

所以回路是：

```
精锐（免费拿到的） → 获得时特质翻倍 → 层数涨得更快
                                    ↓
              远见每10层 +2 金 / 奇迹每100层 +20 金
                                    ↓
                       买更多牌 → 更多「获得时」→ 层数再涨
```

回合末资金清零（除坎诺特），所以这条回路**必须在同一回合内花掉**，它是「回合内滚雪球」而不是跨回合存款。
这就是为什么它叫「倒转」——**表盘越转越快，但每回合清零**。

## 5. 和干员侧机制叠用（上一版的「球」）

缪尔赛思（干员 T6，`maniShip`）：
- 获得时产 1–2 个**变形同构体**（球）
- 球 + 某核心盟约装备（36 件带 `giveBondId`）⇒ 该单位额外算该盟约 **+1 成员**
- **调和**：核心盟约只要有 1 个真成员就 **+1**

⇒ 策略（免费精锐）+ 干员（假成员+调和）是**同一套思路的两个杠杆**：一个把「层数产出」翻倍，一个把「人数档位」造出来。

## 7. 结论（可执行）

1. 缪尔赛思策略的核心价值是把「精锐成本」从 3 张同类卡降到 0，**优先晋升「获得时给层最多」的那张**（惊蛰 / 星熊 / 锏 / 烛煌）
2. 晋升前**先把装备挪好**：晋升会把装备退回手牌，等晋升完再装（否则白折腾）
3. 想吃到「倒转」，必须**同时**在场上有远见或奇迹（10 层=2 金 / 100 层=20 金），否则层数涨了没有金币回流
4. 回合结束资金清零 ⇒ 回流来的金**必须当回合花完**（买牌/刷新/升本）
