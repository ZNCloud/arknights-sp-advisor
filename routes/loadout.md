## 0. 先搞清楚「调配」到底能设什么（官方规则，不是猜的）

来源：PRTS《卫戍协议》总页「物资的调配」段（2026-10-01 版）。

| 你能动的 | 不能动的 | 原文要点 |
|---|---|---|
| 每个干员的**技能**与**模组** | 等阶（阶级） | 「玩家无法卸除或是调整其所在等阶，仅可修改其携带技能和模组」 |
| 「甄选」（＝自选编队）4 个槽位 | 池子里有哪些干员 | 「第Ⅴ阶和第Ⅵ阶中各自存在2个“甄选”槽位，玩家可以选择自身持有的6★干员加入」 |
| 干员持有 / 未拥有（补位） | 潜能（按自己账号） | 「干员的潜能等级始终以自身持有状态为准」 |
| 借用助战补位（最多 20 名） | 补位干员的技能 | 「技能选择由其所在等阶决定…且无法更改」 |

三条对「一套打穿」最关键的死规矩：

1. **甄选干员没有特质。** 原文：「甄选加入的干员不会拥有任何特质。」补位（原型）干员才「继承其补位干员的盟约和特质」。
   → **望、予愿安洁莉娜这类「只能靠自选进队」的干员，进场后没有池子里那条专属特质**，它们买的是「本体 + 三技能 + 模组」，不是叠层。
2. **自选干员按自己账号的潜能 / 练度出战**；补位原型干员**既没有潜能也没有练度**。
3. **一局的禁用干员在简报里公开**（「本次模拟中盟约的缺席情况及被禁用干员」），而**自选编队是开局前锁定、不属于池子，因此不会被本局禁用** ［推断：禁用规则只作用于池子干员］。

### 0.1 自选（甄选）4 个槽位的真实强度

| 槽位 | 非精锐形态 | 精锐形态 |
|---|---|---|
| Ⅴ阶 ×2 | E2 Lv1 / 技能 4 级 / 无模组 | E2 Lv60 / **技能 7 级 / 模组 1 级** |
| Ⅵ阶 ×2 | E2 Lv1 / 技能 4 级 / 无模组 | E2 Lv60 / **技能 7 级 / 模组 3 级** |

- 两个阶的**可选干员池完全相同**：全部「自己持有的、不在池子里的 6★」（本季 72 位）+ 9 位 6★ 原型（Sharp / Stormeye / Pith / Touch / Raidian / Misery / 郁金香 / Mechanist / 领主·Sharp）+（仅Ⅴ阶）6 位 4★ 预备干员。
- 差别只在**精锐形态强度**：Ⅵ阶模组 3 级、Ⅴ阶模组 1 级。
  → **把「靠模组吃饭」的干员放Ⅵ阶槽**（望的 TRP-X 兽形棋盒、荒芜拉普兰德的「狼时」）。［推断，机制来自本仓 `data/chess.json` 的 DIY 槽位 status］
- 联动干员（灰烬、夜刀系、艾丽妮? 等 7 位 `diy.excluded`）**不可自选**。

### 0.2 一个必须先纠正的概念：**「转职」≠「练阶」**

社区说的「能转职」是**改户口（转盟约）**，靠的是**道具**，不是把 2 阶升 3 阶：

> 「要是说的是转户口的话，就是指定装备 + 缪缪的**变形同构体**（史莱姆）可以直接给干员加指定户口（**别跟二升三的拟态物质弄混了**）」——NGA《卫戍协议二期各核心盟约个人运营思路》［社区共识］

对应到本仓数据：

| 道具 | 效果 | 用途 |
|---|---|---|
| **变形同构体**（Ⅵ阶，`chess_item_6_09_e_a`，`canGiveBond: true`） | 携带者**额外获得**「另一件携带装备的 giveBondId」 | 转户口的**开关**，必须和下面某件一起带 |
| **炎国短刀**（Ⅲ阶） | `giveBondId = yanShip`；另每开一次技能 +5% 攻击（叠 10 次） | **转炎** |
| **阿戈尔重刃**（Ⅲ阶） | `giveBondId = egirShip`；攻击力 +40%，攻速 −10 | **转阿戈尔** |
| 维式重锤 / 萨尔贡浓茶 / 拉特兰桥夹 / 谢拉格不融冰 | 各自 giveBondId | 转维 / 转萨 / 转拉 / 转谢 |
| **拟态物质** | 2 阶干员**升阶**（2→3 本），不是改户口 | 别混用 |

两条工程细节（本仓 `server/match/bondsMeta.js` + `shared/plugins/rules.js` 的官方配对规则）：
- **两件都要在同一名干员身上**，缺一件不给盟约；
- 转来的盟约**计入激活人数**（`pieceBonds` 把 granted bond 并进 membership），所以炎 6 人 / 叙拉古 6 人 / 阿戈尔 5 人的阈值都能靠转户口凑。
- ［社区共识］「转户口」社区公认**真香**，但**优先改「主 C 终端」而不是改凑数的**：NGA 原文点名的推荐是「阿戈尔重刃 → 山 / 佩佩」「炎国短刀 → 提丰（任意大C）」「不融冰 → 阿斯卡伦」。
- ［社区共识，反面］另一派认为「小盟约转职性价比低、拟态物质很贵，后期攒着强化主 C 更好」（[手游快报 3/24 避坑指南](https://shouyougame.top/news/arknights-muelsyse-covenant-guide)）。**两条不冲突：改户口（变形同构体）便宜且公认值得，升阶（拟态物质）才该省。**

> ⚠️ 同名混淆：那条「缪尔赛斯转职后**无法**凑齐炎 9 羁绊」是**谣言**，实测转职后可以计入炎 9。［社区共识，同上链接］

## 1. 炎队：社区说的「望」是谁？

### 1.1 结论先说

- **望 ＝ 官方干员「望」**（`char_2027_wang`，6★ 特种·**陷阱师**，势力 炎／岁，百度百科 + [PRTS 望](https://m.prts.wiki/w/%E6%9C%9B) 可查）。是岁家的新成员（2026 新春档）。
- **望不在本期参战名单里**。本期 115 位参战干员中**没有望**（PRTS 参战干员表 + 本仓 `data/chess.json` 双向核对）。
  → 所以社区「搞个望」的准确含义是：**把望塞进「自选（甄选）编队」槽**，她的盟约按实际阵营分配为**核心盟约【炎】**，但**没有特质**。
- 她的三技能分别是 **取势 S1 / 连星 S2 / 天下劫 S3**，模组只有一个 **TRP-X 兽形棋盒**。
- ［社区共识，但要打折］NGA 有贴《感觉望在卫戍的结局挺一般的啊，为什么都在吹》——说明**望在卫戍里不是无脑强**：它强在「自选位 + 三技能 + 模组」这一套本体强度，不强在叠层；纯血炎要叠层还得靠万顷／夕／录武官。
- ［社区共识］**纯血炎队的真核心是「万顷」**（靠买人叠层），且原文明确说纯血炎「刚需万顷电表倒转、特别花时间」，单人勉强、联机时间不够。→ **望更适合当「炎队的终端输出」，不是「炎队的叠层引擎」**。

→ 「不同」是关键：**同一个人升精锐不算两人**，所以要的是 6~9 个**不同名字**的炎干员。

## 2. 叙拉古队：予愿安洁莉娜

### 2.1 身份

- **予愿安洁莉娜**（`char_1015_aglna2`）＝**异格安洁莉娜**，6★ 特种·**巡空者**（skywalker），势力 罗德岛／叙拉古，核心盟约**【叙拉古】**。
- **不在本期参战名单里** → 同样只能走**自选槽**；本季池子里那位「安洁莉娜」（`char_291_aglina`，Ⅴ阶 辅助）是**另一个干员**（原型是 Raidian），别买错。
- **她没有任何模组**（4 个成长形态里 modules 全为空）→ JSON 里 module 只能写 `null`。［本仓 `data/backups.json` 核实］

### 2.2 技能怎么选

| 技能 | 内容 | 在叙拉古体系里的价值 |
|---|---|---|
| **S3 酸橙的心事**（推荐） | 起飞，攻击力 +30%，**60% 对空庇护**，范围 3-9 + 周围 8 格；对 3 个地面 + 1 个飞行造成 305% 物理；飞行敌人减速 40%；**范围内有未被阻挡的可阻挡飞行敌人且自身未阻挡时，会飞过去占位**，31 发弹药 | 叙拉古只有 **6 人**才解锁「部署后进入**等时长隐匿**，隐匿/脱离隐匿 10 秒内 3% 概率真伤 + 恐惧」。她每次「【移动】」按机制算一次**新部署** → 反复刷新攻速加成与隐匿窗口，**是叙拉古里最廉价的「重复触发叠层」按钮**，同时补上叙拉古最缺的**对空** ［推断，机制来自 PRTS 分支特性 + 本仓 `op-aglna2.js`］ |
| S2 重力自定义 | 滑翔 + 浮空 12s / 缚地 22s，攻速大幅缩短、+135% 攻击、转法伤、5 目标 | 强控 + 法伤，适合「本局夜刀/高防怪多、需要钉住地面怪」的局；但她施法 2.5s 期间不攻击，节奏比 S3 慢 ［推断］ |

## 3. 阿戈尔队：转职、吃拐率，和「六级拉普」

### 3.1 「六级拉普」到底是谁

**是荒芜拉普兰德（`char_1038_whitw2`，Ⅵ阶），不是 Ⅱ 阶的拉普兰德。** 两人同期都在池子里：

| 名字 | 等阶 | 职业 | 户口 | 本季特质 |
|---|---|---|---|---|
| 拉普兰德 | **Ⅱ阶** | 近卫·领主 | 叙拉古 | 刷新时若本回合首次主动刷新 → 已激活【叙拉古】层数 **+4/+8**（整备区也有效） |
| **荒芜拉普兰德** | **Ⅵ阶** | 术师（浮游/法术） | 叙拉古 | 战斗中击倒敌人 → 已激活【叙拉古】层数 **+2**；合到精锐后**全队叙拉古都获得该效果** |

→ 社区说「叙拉古的六级拉普」＝ **荒芜拉普兰德**；她既是叙拉古的叠层点，也是叙拉古／阿戈尔体系里**最方便被「转户口」的高费终端**。

### 3.2 阿戈尔体系里她怎么用

阿戈尔核心公式（PRTS）：**【阿戈尔】干员生命值提升（受层数影响）**；战斗开始时【阿戈尔】干员**吞噬身前一格干员**，造成 **5000 物理伤害**并获得其**基础攻击力和阻挡数**，同时叠加 = 被吞噬者等阶的层数（阿戈尔之间优先**更靠左和更靠上**的发起）；**5 名不同阿戈尔 → 前 3 名首次倒地立即复活**。
本仓数值层：阿戈尔 L150 = **×2.85 EHP**，输出倍率 ×1.00（纯物理、**没有术师**）。

于是「后期需要能转职、吃拐率高的」就成了阿戈尔的刚需，因为：

1. **阿戈尔自己输出倍率是 ×1.00**（八条核心里唯一没有输出乘区的），后期 DEF 411/612 面前纯物理只剩 15-43% 效率 → **必须外挂一个法伤/真伤终端**；
2. **阿戈尔的高层数 × 高 EHP** 能把外挂终端喂成数值怪；
3. **转户口只要 3 费（Ⅲ阶）+ 一个 Ⅵ 阶道具**，比换体系便宜。

**具体转法（社区共识 + 本仓道具表）**：

- **要改到阿戈尔户口**：`阿戈尔重刃`（Ⅲ阶，giveBondId = egirShip）+ `变形同构体`（Ⅵ阶，canGiveBond）**同一名干员身上两件** → 该干员额外计入【阿戈尔】，激活人数与吞噬资格都算。
- NGA 原文推荐的转阿戈尔人选：**山**（「山被阿戈尔喂起来以后除了不对空哪都好」）、**佩佩**。
- **荒芜拉普兰德是另一个更贵但更强的选择**：她本来就是法术伤害（正好补掉阿戈尔「无术师、纯物理吃亏」的结构性短板），浮游单元全图索敌（不挑格子、能打远处的飞行/精英），且 `狼时` 模组强化浮游单元伤害叠加。
- ［推断］把荒芜放**最靠左/靠上**的吞噬发起位，让阿戈尔干员吃她，而不是她吃别人——阿戈尔的收益是「吃掉她拿攻击力」，她是**最贵的那块肉**；但如果你要她打输出，就让她当「吃方」（她的基础攻击 312 偏低，吃了也长不大）→ **实战更常见的是：荒芜当输出位、把 乌尔比安（ATK 1362 / HP 4947 全队最高）摆在最前当「优质食材」被吃**。

### 3.3 为什么说她「吃拐率高」

「吃拐」＝吃增伤/攻速/攻击力 buff 的利用率。荒芜拉普兰德在三层 buff 上都拿满：

| buff 来源 | 对她的作用 |
|---|---|
| 【阿戈尔】**吞噬攻击力** | 吞噬得到的是「基础攻击力」，是**加算底数**，之后所有 ×% 加成都在更大的底数上算 |
| 【阿戈尔】**生命值 ×2.85 EHP + 复活** | 她基础 HP 只有 1142（脆），阿戈尔把她的生存拉满，**站得住 = 打得完 18 发弹药/S3 全图追击** |
| 【叙拉古】**部署后攻速 (25+0.8×L)，持续 (32+0.4×L) 秒** | 她的输出模型是「浮游单元持续锁敌」，**攻速直接线性放大**；而且改户口后她**同时是叙拉古 + 阿戈尔双户口**，两套乘区叠在一个人身上 |
| 装备 | 阿戈尔重刃（+40% 攻击 / 攻速−10）+ 变形同构体；或「萨尔贡浓茶 / 迅捷作战粮」这类开局即开技能的装备（社区给红蒂的配法） |
| 精准（附加盟约） | 3 人无视 30% DEF/MRES —— 阿戈尔纯物理队后期唯一破甲通道 |

［推断］加上社区的反面提醒：**阿戈尔对空乏力**（「阿戈尔对空乏力不能抱太大指望」，只有红蒂成型能打）→ 荒芜的浮游单元**可以打空中单位**，这进一步抬高了她在阿戈尔里的地位。

## 4. 自选编队（DIY）四条通用建议

### 4.1 社区普遍放谁

- **本家核心 / 本局必拿的终端**：因为**自选不受本局禁用影响、且开局锁定**，它是唯一「一定在手上」的高费卡。NGA 原文多次出现「自选可以带圣聆初雪或阿斯卡伦 2 技能」「自选位拿斩业星熊」这类说法 → **社区用自选来补「本家抓不到/被禁/雾里看花」的位置** ［社区共识］
- **能改户口的终端**：这类也在自选里挑（提丰、山、阿斯卡伦都是被点名「自选里拿」的）。
- 自选**不是**用来放「凑数」的——甄选干员**没有特质**，放进来的若是叠层位，等于白送一个干员名额。

### 4.2 四条可执行规则

1. **Ⅵ阶两个槽 > Ⅴ阶两个槽**：Ⅵ 阶模组 3 级、Ⅴ 阶模组 1 级。**吃模组的（望、荒芜）必须放 Ⅵ 阶**。
2. **一个「本家终端」+ 一个「转户口载体」**：炎＝望 +（年/重岳/黍/斩业星熊）；叙拉古＝予愿安洁莉娜 + 荒芜；阿戈尔＝荒芜（或 山/佩佩）+ 克莱门莎。
3. **本局简报出来后 30 秒内改自选**：简报公开了「可用的盟约 + 被禁干员」，如果本家核心被禁，就把自选从「补强」改成「顶替」（例：炎被禁 → 烛煌进 ban，自选改放望 + 年 + 斩业星熊 + 司霆惊蛰，改打炎 6 人）。
4. **别塞联动/联动池外**：7 位联动干员在 `diy.excluded` 里，选不了；另外**同名干员同阶只能上一个自选槽**。

### 4.3 一套「三修」的自选模板（打穿任何局用）

| 槽位 | 干员 | 覆盖 |
|---|---|---|
| Ⅵ-1 | **望**（3 技能·天下劫 / 兽形棋盒） | 炎队终端；也能当通用法伤陷阱位 |
| Ⅵ-2 | **荒芜拉普兰德**（2 技能·逐猎狂飙 / 狼时） | 叙拉古终端；转阿戈尔户口后当阿戈尔终端 |
| Ⅴ-1 | **予愿安洁莉娜**（3 技能·酸橙的心事） | 叙拉古重复部署引擎 + 对空 |
| Ⅴ-2 | **山** 或 **克莱门莎** 或 **斩业星熊** | 山＝阿戈尔转户口肉盾（吃满吞食）；克莱门莎＝阿戈尔户口；斩业星熊＝炎队补人 |

> ［推断］这套模板的依据是：三套体系的「终端」都不在池子里（望、荒芜、予愿安洁莉娜都是池外/自选），而池子提供的是**叠层引擎**（夕、录武官、拉普兰德、深巡、幽灵鲨）。**引擎靠池子抓、终端靠自选固定**——这就是「一套打穿任何局」的真正含义。

## 5. 潜能 / 练度的取舍

| 事实 | 结论 |
|---|---|
| 默认 **满潜 6 / 练度 3（精英2 Lv60）**（`shared/potential.js`：`POTENTIAL_DEFAULT=6`、`CULTIVATE_DEFAULT=3`，owner 决定「默认满潜满加成」） | **默认就是最优，别降** |
| 潜能只影响**属性叶子**（费用、攻击、再部署…）和天赋的 `potBelow` 档位 | 降潜**只减不加**，没有任何「低潜吃补位」的机制入口 |
| 练度是 `char_attribute_mul`：×1 / ×1.05攻 / ×1.1攻×1.05防 / ×1.1全属性 | 降练度**只会更弱** |
| **只有「已持有」的干员才有潜能/练度**；**补位原型干员两者都没有** | 想吃补位只能勾「未拥有」，**换来的是整块换成原型 6★（无特质、无潜能、无练度）** |
| 补位干员技能由等阶决定，**不可改**；且「玩家自身已持有某一干员时…无法切换至填补干员」 | **有账号就别想着故意标未拥有**，系统不给你切 |
| 补位的唯一价值：**用助战（最多 20 名）补你没有的干员**，或拿「罗德岛特派高级资深干员」的职业原型（Sharp/Stormeye/Pith/Touch/Raidian/Misery…） | 用在对职业 / 对空 / 控场有硬需求的局，**不是用来吃 buff 的** |

**结论：默认满潜满练度是最优解；「留低练度吃补位」这个操作不成立。**［推断，依据本仓 `shared/potential.js` + `server/match/player/basics.js` `cultivationFor`/`fieldsStandIn` 的实现；PRTS 原文「干员的潜能等级始终以自身持有状态为准」作为官方支撑］

**唯一例外**：**不满潜会直接坑到「望」这类按持有量算召唤物的干员**——铸子「最多拥有 7 枚」在满潜是 8 枚（`op-wang.js` 注释），低潜少一枚棋子。所以**满潜对望是实打实的 +1 枚棋子**。

## 6. 「一套干员打穿任何局」成立吗？

### 6.1 分难度看

| 模式 | 可用核心盟约 | 本局禁核心数 | 结论 |
|---|---|---|---|
| **标准模拟（单人 9 回合 / 多人 14 回合）** | 5 条：炎/萨尔贡/维多利亚/谢拉格/叙拉古 | **0**（只禁 1 条附加） | **一套成立**：核心几乎不会被禁，自选也不受影响 → 只受「池子随机」影响 |
| **入门 / 团队（训练）** | 8 条 | 0 | 一套成立 |
| **险境 / 绝境 / 终极** | 8 条 | **禁 3 核心 + 4 附加** | **一套必崩**，要准备「骨架 + 壳」 |

数据来源：本仓 `data/config.json` `modes.*.activeBondIds` + `bans`（`NORMAL/HARD/ABYSS: core 3, addon 4`；`FUNNY: core 0, addon 1`），与 `NUMBERS.md` §6 一致。

### 6.2 禁用到底禁谁（关键）

本仓 `data/config.json` 的 `bans.rule` 原文：

> **banned iff every bond of a visible non-DIY chess is in (drawn set D ∪ mode.inactiveBondIds)**

也就是说：**当一名干员的「全部盟约」都被禁，他才会被移出池子**——不是「任一盟约被禁就删牌」。
例：
- 炎被禁、维多利亚没被禁 → **烛煌还在**（它同时是维多利亚）；
- 炎 + 维多利亚都被禁 → **烛煌被移出池子**（这时只能靠自选拿望/年/重岳/黍/斩业星熊顶）。
- **自选（DIY）干员不在 `bans.rule` 的靶子里**（`non-DIY chess`），所以**自选干员永不被本局禁**。

### 6.3 社区的应对（［社区共识＋推断］）

1. **不押单一体系**：标准局里从没被禁的核心任选一个终端；**助力 + 远见/奇迹 + 精准**是非核心骨架，无论本局禁什么都搭得上（`NUMBERS.md` §8）。
2. **多准备「壳」，不是多准备「一套」**：社区原文的做法是「看本局简报里的联盟再定策略」（「这次卫戍2期…可以看到六个阵营，炎保前期，谢拉格萨尔贡保中期，拉特兰维多利亚保后期」）。
3. **靠自选兜底**：自选 4 槽 = 4 张「本局一定到手」的牌，是**唯一能对冲禁用 + 抽卡随机**的机制。理想状态：**Ⅵ 阶自选放终端、Ⅴ 阶自选放「万一终端被禁也能改户口」的载体**。
4. **队友维度**：多人局里，如果队友不碰阿戈尔（社区：「绝境阿戈尔没人玩…四号位就会跑」），你**自选一张荒芜 + 转户口**就能把阿戈尔从「没人要」变成「有人 C」。

### 6.4 最终答案

> **「一套调配打穿任何局」在标准模拟里成立（核心 0 禁），在险境以上不成立。**
> 险境以上的正确形态是 **「1 套通用骨架 + 3 个可替换终端壳 + 4 个固定自选槽」**：
> 骨架＝助力/远见/奇迹/精准（不进调配，是局内抓牌）；
> 壳＝炎（望）/叙拉古（予愿安洁莉娜）/阿戈尔（荒芜+转户口），按本局简报挑一个；
> 自选槽＝**不随禁用变化的那部分**，这才是真正「打穿任何局」的那张底牌。

## 8. 五分钟速查

1. **炎**：自选 Ⅵ 放 **望（3 技能·天下劫／兽形棋盒）**；池子抓 **夕(S3/SPC-X) → 烛煌(S3/PRI-X) → 余(S3/PRP-X) → 录武官 → 星熊 → 惊蛰**；经济靠 **两个诗怀雅 + 锡人**；目标 **6 名不同炎**（吃炎佑），能到 9 更好。
2. **叙拉古**：自选 Ⅵ 放 **予愿安洁莉娜（3 技能·酸橙的心事／无模组，靠位移反复触发部署）**；池子抓 **拉普兰德(S2 狼魂) + 逐光 + 铃兰 + 忍冬 + 伺夜 + 荒芜(S2)**；**必须凑 6 人**（隐匿真伤），否则「叠了没伤害」。
3. **阿戈尔**：自选 Ⅵ 放 **荒芜拉普兰德（S2／狼时）**，身上同时带 **阿戈尔重刃 + 变形同构体** 转阿戈尔户口；池子按 **幽灵鲨 → 深巡 → 乌尔比安(52) → 红蒂(S3/BAR-Y) → 歌蒂/歌鲨 → 海霓/水月** 站成人体蜈蚣，**越能打的越站最后**；附加盟约配 **不屈 + 精准**。
4. **潜能/练度**：保持默认 **满潜 6 / 练度 3**，没有「低练度吃补位」这条捷径。
5. **禁干员**：标准局几乎不禁核心，一套能打；**险境以上禁 3 核心**，靠「自选 4 槽 + 骨架（助力/远见/奇迹/精准）」兜底，并按简报把自选从「补强」改成「顶替」。
